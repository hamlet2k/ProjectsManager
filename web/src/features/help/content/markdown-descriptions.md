# Markdown in descriptions

Task and project descriptions support a safe Markdown subset. Expanded task views render Markdown.

## Common syntax

| Syntax | Result |
|--------|--------|
| `**bold**` | **bold** |
| `_italic_` | _italic_ |
| `` `code` `` | inline code |
| `# Heading` | Heading |
| `- item` | Bullet list |
| `1. item` | Numbered list |
| `- [ ] todo` | Checklist |
| `[text](https://…)` | Link |
| `> quote` | Blockquote |
| `---` | Horizontal rule |

## Tips

- Prefer short checklists in descriptions for multi-step work.
- Links open in a new tab when rendered.
- The task form has a compact **Markdown help** cheatsheet next to the description field.
