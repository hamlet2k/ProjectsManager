# Sharing a project

Share a project so others can view or edit tasks with you. Changes appear for everyone via realtime updates.

## Invite someone

1. Open the project.
2. Use **Share** (owners / managers).
3. Enter their email and choose a role.
4. They receive an invitation (notification / email depending on setup) and accept it.

## Roles (typical)

| Role | What they can do |
|------|------------------|
| **Viewer** | See tasks and links; cannot edit or delete |
| **Editor** | Create, edit, complete tasks; use voice if available |
| **Owner / manager** | Settings, sharing, delete project (owner) |

Exact labels follow what you pick in the share dialog.

## Accepting an invite

- Open **Notifications** (bell) and **Accept** or **Decline**.
- Or open the invite link if you received one.

## Tips

- Viewers who try to delete will not change the board — the app should show a clear error.
- GitHub tokens and CLI tokens are **personal**: each user configures their own GitHub PAT and CLI access. Sharing a project does not share your tokens.
