# Import and export

Move task lists between Projects Manager and other tools using the board **copy / transfer** controls.

## Project setting: advanced export

In project settings:

- **Advanced export on** — the copy control opens a fuller **Import / Export** flow (formats, options).
- **Advanced export off** — copy pastes a simple checklist for quick sharing.

## Export

1. Open the project board.
2. Use the copy / export control in the board chrome.
3. Choose what to include (for example open vs completed, depending on the dialog).
4. Copy the result or download as offered.

## Import

1. Open Import from the same transfer UI (when advanced export is enabled).
2. Paste a supported format.
3. Review and confirm creation of tasks/tags as prompted.

## Tips

- Import creates tasks **in this project** under your permissions.
- GitHub issue links are not always recreated from plain text export — re-link if needed.
- Large pastes may take a moment; wait for the success toast.
