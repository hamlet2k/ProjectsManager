# Getting started

Projects Manager is a multi-project task board. Each **project** holds tasks, tags, optional shares, and optional GitHub linking.

## Projects

- From the home screen, create a project (name + optional description).
- Open a project to work on its board.
- Owners can edit project settings (dependencies, export style, AI prompt) and delete the project.

## Tasks

- Add tasks from the quick-add bar or the **+** control.
- **Complete** a task with the checkbox; use the floating **Done** filter to show or hide completed work.
- **Edit** opens the task modal (title, description, due date, tags).
- **Rank** order is drag-and-drop when sort is Rank and filters are clear.
- Descriptions support **Markdown** (see [Markdown in descriptions](?help=markdown-descriptions)).

## Tags

- Tags group and filter work on the board.
- Sort by tags to see groups; multi-tag tasks appear in one group depending on board rules.
- Filter by tag from the filter control.

## Search, sort, and filters

- **Search** is always available in the board chrome.
- **Sort** is a separate floating control (rank, due date, tags, and similar).
- **Completed** has its own toggle so it is not buried inside filters.

## Tips

- Use **dependencies** (if enabled on the project) for blocked-by / blocks relationships.
- Voice and AI enhance are available to editors — see [Voice assistant](?help=voice-assistant).
- To invite others, see [Sharing a project](?help=sharing-projects).
