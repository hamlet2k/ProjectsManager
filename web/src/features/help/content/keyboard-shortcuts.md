# Keyboard shortcuts

Shortcuts speed up search, filters, and **voice push-to-talk**.

## Where to edit

**Settings → Keyboard shortcuts**

1. Click a row.
2. Press the new key combination.
3. **Esc** cancels capture.
4. **Reset all** restores defaults.

Bindings are stored **on this device** (browser local storage), not as a global account preference.

## Common actions

Exact defaults appear in Settings; they typically include:

- Focus search / clear filters  
- Board navigation helpers  
- **Hold for voice** (push-to-talk) when a project board is open  

Voice hold uses the same idea as the floating mic: press and hold the bound key while speaking, then release.

## Tips

- Avoid stealing browser or OS shortcuts you rely on.
- If a shortcut seems dead, click into the page (not the address bar) and check you are not typing in an input field.
- Buttons with shortcuts should show the binding in their tooltip when the UI exposes it.
